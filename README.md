## 📱 How to Deploy to GitHub Pages (Using Your Phone Only)

Since you don't have a laptop right now, follow these steps using **only your phone**. You'll need the **GitHub mobile app** and a **file manager app**.

---

### Step 1: Download the Required Apps

1. **GitHub App** — Download from Play Store/App Store
   - Search: "GitHub"
   - Install and sign in with your GitHub account (or create one)

2. **File Manager** — Use your phone's built-in file manager or download one like:
   - **Files by Google** (Android)
   - **Documents by Readdle** (iOS)
   - Or any file manager that lets you create folders and move files

---

### Step 3: Create a GitHub Repository

1. Open the **GitHub App** on your phone
2. Tap the **+** button (bottom center)
3. Select **"New repository"**
4. Fill in:
   - **Repository name:** `ury-portfolio` (or any name you want)
   - **Description:** "My creative portfolio website"
   - Make it **Public** ✅
   - Check **"Add a README file"** ✅
   - Tap **Create repository**

---

### Step 4: Upload Your Files

#### Method A: Using GitHub App (Easiest)

1. In your new repo, tap **"Add file"** or the **+** button
2. Select **"Upload files"**
3. Tap **"Choose your files"**
4. Navigate to your `ury-portfolio` folder
5. **Select ALL files** (tap and hold one file, then tap others to select multiple)
6. Tap **"Open"** or **"Upload"**
7. Scroll down and tap **"Commit changes"**

#### Method B: Using GitHub Website (If App Doesn't Support Upload)

1. Open your phone's **browser** (Chrome/Safari)
2. Go to: `github.com/yourusername/ury-portfolio`
3. Tap **"Add file"** → **"Upload files"**
4. Tap **"Choose your files"**
5. Select all files from your folder
6. Tap **"Commit changes"**

---

### Step 5: Enable GitHub Pages

This is the magic step that turns your repo into a live website!

1. In the GitHub App or browser, go to your repository
2. Tap the **☰ menu** (top left) or scroll to find **"Settings"**
3. Scroll down to **"Pages"** section (under Code and automation)
4. Under **"Source"**, select: **Deploy from a branch**
5. Under **"Branch"**, select: **main** and **/(root)**
6. Tap **"Save"**

⏳ **Wait 2-5 minutes** for GitHub to build your site.

---

### Step 6: Your Website is Live! 🎉

After a few minutes, your website will be available at:

```
(https://lamonjesury2004-cpu.github.io/Ury-portfolio/)
```

Replace `yourusername` with your actual GitHub username.

**Example:** If your username is `urydesign`, your site will be:
```
https://urydesign.github.io/ury-portfolio
```

## 🔄 How to Update Your Website Later

If you want to change something:

1. Edit the `index.html` file (you can use a text editor app on your phone)
2. Go back to GitHub
3. Tap **"Add file"** → **"Upload files"**
4. Upload the new `index.html`
5. GitHub will automatically update your live website in a few minutes!

## 🛠 Troubleshooting

| Problem | Solution |
|---------|----------|
| Images not showing | Make sure image filenames match exactly (case-sensitive!) |
| Website not loading | Wait 5 minutes after enabling Pages, then refresh |
| "404" error | Check that `index.html` is in the root of your repo, not in a folder |
| Can't upload multiple files | Upload them one by one, or use the browser instead of the app |
| Site shows old version | Clear browser cache or wait a few minutes |
